# Ναταλία Φούρλα MD, MSc

Ιστότοπος για ωτορινολαρυγγολόγο και πλαστική χειρουργική προσώπου, Αθήνα.

Next.js 16 (App Router, Turbopack) + Tailwind v4 + Motion.

## Πού αλλάζει το περιεχόμενο

Κάθε στοιχείο της επιχείρησης (υπηρεσίες, ωράριο, τηλέφωνο, διεύθυνση,
βιογραφικό) βρίσκεται στο `lib/content.ts`. Τα components δεν περιέχουν
hard-coded στοιχεία, οπότε οι αλλαγές γίνονται μόνο εκεί.

## Λογότυπο

Ο πελάτης έστειλε ένα JPEG με έξι προτάσεις λογοτύπου σε πλέγμα 3x2
(`tools/logo-source-sheet.jpg`). Επιλέχθηκε το κάτω μεσαίο: λευκό line art σε
σκούρο φόντο. Το `tools/prepare-logo.py` κόβει το πλακίδιο και ανακτά το κανάλι
διαφάνειας από τη φωτεινότητα, παράγοντας τα αρχεία στο `public/brand/`.

Τα αρχεία είναι raster 512px, όχι vector. Για μεγάλα μεγέθη (πινακίδα, έντυπα)
χρειάζεται καθαρό ξανασχεδίασμα σε vector.

## Video

Το `tools/make-logo-video.py` παράγει τα αρχεία στο `public/video/`. Κάθε καρέ
είναι καθαρή συνάρτηση του χρόνου, οπότε το render είναι ντετερμινιστικό.

Το λογότυπο «ζωγραφίζεται» ακολουθώντας γεωδαισιακή απόσταση κατά μήκος των
ίδιων των γραμμών, όχι με απλό wipe. Τα hero αρχεία ξεκινούν και τελειώνουν στο
μαύρο ώστε να κάνουν loop χωρίς ραφή.

```bash
python3 tools/make-logo-video.py --fast   # preview μισής ανάλυσης
python3 tools/make-logo-video.py          # τελικό
```

## Φωτογραφίες

Οι εικόνες στο `public/img/` είναι παραγόμενες, ατμοσφαιρικές λήψεις. Δεν
απεικονίζουν το πραγματικό ιατρείο, ασθενείς ή αποτελέσματα επεμβάσεων. Η φόρμα
του πελάτη δεν περιείχε χρησιμοποιήσιμο φωτογραφικό υλικό. Όταν παραδοθούν
πραγματικές φωτογραφίες (πορτρέτο ιατρού, χώρος ιατρείου), αντικαθιστούν τα
αρχεία με τα ίδια ονόματα.

